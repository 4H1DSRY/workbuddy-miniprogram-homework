# 喵管家 · 猫咪管理小程序

Homework 4 作业项目。微信**原生**小程序（WXML + WXSS + JS），无云开发、无 npm、无任何网络请求，数据全部落在本机 Storage。

---

## 一、30 秒打开（3 步）

1. 打开「微信开发者工具」→ 微信扫码登录
2. 顶部菜单 **设置 → 安全设置 → 开启「服务端口」**
   （开了之后我才能用命令行打开项目、驱动它做自动验证和录屏；不开就只能你手动点）
3. 首页「导入项目」→ 目录选
   `D:\Claw\workbuddy-course\homework-4\miaoguanjia`
   → AppID 那一栏点 **「测试号」** → 确定

> `project.config.json` 里已写入 `"appid": "touristappid"`，直接打开不会卡在 AppID 上。

打开后模拟器应立即出现首页（三只示例猫：团子 / 芝麻 / 豆豆）。

## 二、换成你自己的猫照片

把照片放进 `miaoguanjia/images/cats/`，**覆盖同名文件**即可，代码不用改：

| 文件名 | 对应 | 建议 |
| --- | --- | --- |
| `cat1.jpg` | 团子 | 正方形，≥ 400×400 |
| `cat2.jpg` | 芝麻 | 同上 |
| `cat3.jpg` | 豆豆 | 同上 |
| `default.jpg` | 新增猫咪的默认头像 | 同上 |

猫的名字、品种、生日、体重都能在 App 内改：**我的 → 猫咪档案 → 点某只猫**。
（示例三只猫只是种子数据，随便改。）

## 三、功能清单

| 页面 | 做了什么 |
| --- | --- |
| **首页** | 多猫横向切换、三环状态（饱食/饮水/心情）、体重与增减趋势、今日摄入进度条、快捷操作（投食 / 喂水 / 逗猫 / 称重）、今日提醒、最近记录 |
| **记录** | 猫咪切换、`canvas 2d` 体重趋势折线图、按类型筛选（全部/喂食/饮水/体重/护理）、按天分组的时间线 |
| **我的** | 统计卡、猫咪档案增删改、3 台虚拟设备开关、提醒开关 + 提醒时间选择、关于、重置演示数据 |
| **档案编辑** | 新增/编辑猫咪：选头像（相册或相机）、名字、品种、性别、生日、体重、每日目标、备注、删除 |

数据流：所有写操作走 `utils/store.js`，页面 `onShow` 重新读取 → 一个页面改了，切回另一页立刻是最新的。

## 四、目录结构

```
miaoguanjia/
├── app.js / app.json / app.wxss      # 全局入口、路由与 TabBar、全局样式
├── project.config.json               # 项目配置（appid = touristappid）
├── sitemap.json
├── pages/
│   ├── index/      # 首页
│   ├── records/    # 记录（含体重折线图）
│   ├── mine/       # 我的
│   └── cat-edit/   # 猫咪档案新增 / 编辑
├── utils/
│   ├── store.js    # 数据层：种子数据、增删改查、统计、格式化、业务校验
│   └── theme.js    # 色彩 token（JS 侧）：canvas 与 conic-gradient 取色
└── images/
    ├── tabbar/     # 6 个 tabBar 图标（常态 + 选中）
    └── cats/       # 猫咪头像（你替换这里）
```

同目录下另有三个**开发辅助文件**（不属于小程序包，别上传）：

- `make_assets.py` — 生成 tabBar 图标与占位头像的脚本
- `check.js` — 静态校验（JSON 语法、页面文件齐全、WXML 标签配对、事件处理函数存在、图片路径存在、**设计 token 一致性**）
- `simulate.js` — 打桩 `wx` API，在 Node 里真跑一遍数据层和四个页面逻辑

## 六、技术点（写报告或录屏旁白可以直接用）

- **零网络**：全部数据走 `wx.setStorageSync`，Console 天然干净，没有域名/请求失败的可能
- **数据层收口**：页面不直接碰 Storage，统一走 `utils/store.js`；连表单校验也放在数据层（`validateCat`），页面只负责显示 `msg`
- **设计 token 双份对齐**：`app.wxss` 定义 CSS 变量，`utils/theme.js` 提供同名同值的 JS 常量，`check.js` 强制校验两者一致
- **`canvas 2d` 手绘折线图**：渐变填充、端点、坐标轴标签，按 `pixelRatio` 做设备像素适配
- **`conic-gradient` 状态环**：角度 = 百分比 × 3.6deg，由 `theme.ringGradient()` 统一生成
- **本地持久化头像**：`wx.chooseMedia` 拿到临时路径后，用 `FileSystemManager.saveFile` 转成永久路径，重启不掉图
- 删除二次确认、空状态、下拉刷新、`wx.showModal` 可编辑弹窗
