2. 顶部菜单 **设置 → 安全设置 → 开启「服务端口」**

## 二、换成你自己的猫照片

把照片放进 `miaoguanjia/images/cats/`，**覆盖同名文件**即可，代码不用改：

| 文件名 | 对应 | 建议 |
| --- | --- | --- |
| `cat1.jpg` | 团子（布偶猫） | **3:2 横幅**，1200×800，≤ 150 KB |
| `cat2.jpg` | 芝麻（玄猫） | 同上 |
| `cat3.jpg` | 豆豆（三花） | 同上 |
| `default.jpg` | 新增猫咪的默认头像 | 同上 |

为什么是 3:2 而不是正方形：首页照片槽就是 3:2，`mode="aspectFit"` 会把整张图
原样放进去、一个像素都不裁。比例不符时不会切掉猫，而是在槽位里留边——
留边比切掉半张脸好。裁剪用 `python tools/prep_cat_photo.py 原图 输出`。

猫的名字、品种、生日、体重都能在 App 内改：**我的 → 猫咪档案 → 点某只猫**。
（示例三只猫只是种子数据，随便改。）

> 仓库里的三张示例图是 Pexels 免费授权照片，**不是本项目作者的猫**，来源见
> `docs/图片来源.md`。三只猫的档案是虚构的演示数据。

## 四、设计：纸墨朱

界面按「纸、墨、朱」三层配色收口，规则只有三条：

| 层 | 取值 | 用途 |
| --- | --- | --- |
| 纸 | `#FAF8F4` / `#FFFFFF` | 底色与需要浮起的块 |
| 墨 | `#1E1B19 → #C9C2B8`（六级灰阶） | 文字、线、图标 |
| 朱 | `#AE412D` | **每页只留一个焦点**（首页=照顾分环，记录=体重，编辑=无） |

配套的五条硬规矩：

- **不画阴影**。分隔靠留白和 1px 发丝线，框不再重复画一遍。
- **圆角收口**：卡片 8rpx，按钮与徽章 4rpx。没有胶囊、没有大圆角。
- **字号只有四层**：20（注释）/ 24（标签）/ 68（猫名）/ 92（体重数值），中间刻意空着。
- **不用 emoji 当图标**。全部线条图标由 `make_icons.py` 用 Pillow 4× 超采样绘制，墨黑描边，22px 下仍可辨。
- **控件不染色**。开关、筛选、选中的 cat chip 全部走墨色（实心墨底或发丝描边），朱色只留给数字。

字体走全宋体（`Songti SC` / `STSong` / `Noto Serif SC` 逐级回退），行高 1.62。
> 注意：Android 真机通常没有宋体，会回退到系统黑体；模拟器与 iOS 上才是宋体效果。

| `e2e.js` 端到端流程（74 项断言） | 全部通过 |
| 开发者工具内编译 | 通过——四页渲染正常，状态栏 `0 错误 / 0 警告` |

冒烟测试覆盖了：种子数据、今日摄入统计、体重趋势、按天分组、四页生命周期、投食/喂水/逗猫/称重四种操作对数据的真实改写、筛选、切猫、设备开关落库、新增/编辑/删除猫咪的完整闭环，以及数据层的 `validateCat` 边界值（空名 / 超长名 / 体重 0 与 31 / 目标 19 与 601 / 首尾空格修剪 / 两位小数归一化）。

其中两条是**自洽性断言**，专门防上一版那个坑：

```
eq('首页: 进食百分比与绝对值自洽', pct.food, round(pct.foodAbs / pct.foodTarget * 100))
eq('首页: 饮水百分比与绝对值自洽', pct.water, round(pct.waterAbs / pct.waterTarget * 100))
```

上一版首页同时显示「饱食度 68%」和「进食 45 / 200 g」（= 22.5%），两个数互相打脸。现在百分比与绝对值同出 `store.intakePercent()` 一个数据源。

> 补一句：静态校验与逻辑断言通过，**不等于**在微信开发者工具里能正常渲染。这两层现在都过了；页面内的逐项点击手验清单见 `docs/验收清单.md` C 组。

## 七、技术点（写报告或录屏旁白可以直接用）

- **零网络**：全部数据走 `wx.setStorageSync`，Console 天然干净，没有域名/请求失败的可能
- **数据层收口**：页面不直接碰 Storage，统一走 `utils/store.js`；连表单校验也放在数据层（`validateCat`），页面只负责显示 `msg`
- **设计 token 双份对齐**：`app.wxss` 定义 CSS 变量，`utils/theme.js` 提供同名同值的 JS 常量，`check.js` 强制校验两者一致（canvas 与 conic-gradient 读不到 CSS 变量，只能走 JS）
- **`canvas 2d` 手绘折线图**：渐变填充、端点、坐标轴标签，按 `pixelRatio` 做设备像素适配
- **`conic-gradient` 状态环**：角度 = 百分比 × 3.6deg，由 `theme.ringGradient()` 统一生成
- **本地持久化头像**：`wx.chooseMedia` 拿到临时路径后，用 `FileSystemManager.saveFile` 转成永久路径，重启不掉图
- 触觉反馈（`wx.vibrateShort`）、删除二次确认、空状态、下拉刷新、`wx.showModal` 可编辑弹窗
