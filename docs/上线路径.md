# 「已上线」这件事的真实门槛

作业原文要求交一份**已上线**小程序的屏幕录制。你目前没有小程序账号，这条先说清楚，免得白等。

---

## 一、硬约束（已核实）

| 事项 | 事实 | 来源 |
| --- | --- | --- |
| 未备案能否发布 | **不能**。备案通过后才可提交代码审核、正式发布 | 微信开放社区备案公告 / 服务市场 FAQ |
| 备案时长 | 平台初审 **1–2 个工作日** → 工信部短信核验（**24 小时内**完成，超时驳回）→ 管局终审 **1–20 个工作日** | 微信服务市场备案 FAQ（2026 年 1/3/5 月期） |
| 管局法定上限 | 材料齐全的，**20 个工作日**内予以备案 | 工信部《非经营性互联网信息服务备案管理办法》第 12 条；上海管局 2026-09 答复 |

## 二、三条路径，选一条

### 路径 A（推荐）：现在注册 + 备案，本次先交体验版录屏

理由：体验版本身就是**真实小程序**（有 AppID、上传到微信服务器、手机微信能打开），只是没对公众开放。录屏里能真实操作，Console 干净，且整套流程你已经走通。等备案下来再提审，不耽误交作业。

- 今天：注册 → 拿 AppID → 上传代码 → 生成体验版二维码 → 手机微信打开
- 同步：提交备案（材料齐的话 10 分钟填完）
- 1–3 周后：备案通过 → 提审 → 发布

### 路径 B：只做体验版，不碰备案

最省事。体验版有效期长，但**不能"发布"**，所以不满足字面上的"已上线"。适合老师实际只看功能的情况。

### 路径 C：等备案下来再录

最保险但最慢。只在交作业时间宽裕时选。

## 三、注册与备案清单（个人主体）

**注册**（https://mp.weixin.qq.com → 立即注册 → 小程序）

- 一个**从未绑定过公众号/小程序**的邮箱
- 身份证 + 已实名的微信号（扫码验证）
- 手机号
- 拿到 AppID 后填进 `miaoguanjia/project.config.json` 的 `"appid"` 字段（替换 `touristappid`）

**备案**（后台 → 设置 → 小程序备案）

- 身份证、常用手机号、**纯白背景免冠核验照片**（无反光、无滤镜）
- 主体负责人 24 小时内完成 12381 短信核验
- 备案服务内容：选 **工具 → 健康管理**（身高体重等健康记录）或 **工具 → 信息查询**。
  ⚠️ 「宠物」相关经营类目对个人主体大概率不开放，**且类目必须和实际功能匹配**，选错会被打回。这一点建议以后台当时可选项为准（待确认）。

**上传与提审**

1. 开发者工具右上角「上传」→ 版本号 `1.0.0`，备注写清功能
2. mp 后台 → 管理 → 版本管理 → 开发版本 → 提交审核（每个核心页面至少传 1 张截图）
3. 审核通过 → 发布（首次建议分阶段发布）
