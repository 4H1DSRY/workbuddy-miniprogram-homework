## 建议执行顺序

**第一批（现在就能做，不需外部输入）**

```
E1 → E2        先有守门人，后面每次改动都有反馈
E3 → E4        项目根干净，变更可追溯
X2             对比度是纯计算问题，改动局部，风险低
```

**第二批（等真猫照片与真机）**

```
A1 → D1        有了照片才能录屏，D1 是唯一的 P0 交付物
X1             需要 Android 真机，可与 D1 同批处理
```

**第三批（M3 纵深，作业交完之后）**

```
F2 → F1        F2 先做：它让记录可改，才谈得上导出有意义的数据
F3 → F4        F3 有实际使用价值，F4 是视觉增强
D2 → D3        报告与 README 在功能稳定后再写，避免返工
```
