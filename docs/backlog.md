## 明确的「不做」

| 条目 | 不做的理由 |
| --- | --- |
| **AI 疾病诊断（给病名）** | 微信「宠物医院/兽医（含在线问诊）」类目**个人主体不可从事**；且需「深度合成」类目，仅企业主体可申请。改走「就诊描述生成器」 |
| **AI 生成卡通形象** | 属「深度合成 - AI 绘画」，个人主体无法申请类目。改走「预置形象 + 换装」 |
| **用大模型润色就诊描述** | 一旦调模型就变回生成式 AI，个人主体过不了审。必须模板拼接 |
| 云开发 / 多设备同步 | 破不变量 1，且作业不要求 |
| 账号与登录 | 单机单用户是明确边界 |
| 社区 / 分享排行榜 | 与「每天 30 秒记完」的核心场景无关 |
| 接入第三方宠物硬件 | 无真实设备，做了也是假数据 |
