### 镜头 2 ｜ 0:18 – 1:15 首页 + 用量面板

**画面**：首页（一屏内全部内容）
**操作**：
1. 依次点顶部 **团子 → 芝麻 → 豆豆**，每只停 1 秒（三只猫数据各自独立）
2. 点回 **团子**，鼠标依次划过 **进食 160/200 g、饮水 200/230 ml、逗猫 15/30 min** 三条刻度
3. 在 **心情** 那行点第 4 格 → 右侧文字从「未知」变成「不错」
4. 点 **投食** → 底部升起面板，停 1 秒让观众看清「今天已 160 / 200 g」和五档 20 / 30 / 40 / 50 / 60
5. 点 **60** → 提示行变成 **记完 228 / 200 g · 超出 28 g**（变朱色）→ 停 1 秒
6. 点 **记录** → 弹出提醒，停 2 秒读正文 → 点 **仍然记录**
7. 〔可选 10 秒〕点 **喂水** → 点 **100** → 记录 → 弹出只有「知道了」的告知框 → 点掉
**旁白**：

> 首页一屏说完，不用滚动——滚一下就会犹豫，一犹豫就会跳过一天。
> 上面这排可以切猫，每只猫的数据是独立的。
> 三条刻度里，进食和饮水是从今天的记录累加出来的，逗猫是今天陪它玩的分钟数。
> 心情这一行是我自己点的，一到五格。它不进照顾分：照顾分算的是「我做了什么」，
> 自评记的是「我看到什么」，把后者折成百分比只会多出一个假精确的数字。
> 下面五个动作：投食、喂水、逗猫、称重、症状。
> 投食原先是一键 40 克——40 克是别人家的数。现在点开是一个面板，
> 五档常用量加一个输入框，选多少记多少；面板底下这行是预告，记之前就告诉你今天会到多少。
> 超了会弹一句提醒，但不拦。参考量是按体重和粮估出来的，不是硬标准，
> 真正知道它吃没吃饱的是端着碗的人。
> 喂水超过参考量也提示，但不劝你少给——猫多喝水不是问题，
> 该被记下来的是「连续几天都比平常多」这件事。

### 镜头 3 ｜ 1:15 – 2:00 症状初诊 → 就诊描述（核心演示）

**画面**：首页 → 点第五个动作 **症状**
**操作**：
1. 停 1 秒，让观众看清顶部那句「仅记录症状并生成就诊描述，不提供诊断或医疗建议」
2. 在「用自己的话说」里打一句：`今天一直趴在沙发底下不出来，叫它也不应`
3. 往下滚，勾选 2–3 个症状（比如「不吃东西」「躲起来」）
4. 选「持续多久」= 一天
5. 点 **生成就诊描述** → 跳报告页
6. 停 2 秒读报告结构，再点 **完成** 回首页
**旁白**：

> 这块是这个作业里花时间最多的。它不诊断——个人主体做不了在线问诊，所以我把它做成了另一件事：
> 把「我说不清猫怎么了」变成一份能递给医生的话。
> 先让人用自己的话写，再给勾选清单，顺序不能反：先给选项会把观察范围框死。
> 生成的是就诊描述——症状、持续多久、这段时间的进食饮水记录，按时间排好。

## 常见翻车点

| 现象 | 处理 |
| --- | --- |
| 首页全是 0、照顾分 0、`今天 · 0 条记录` | 演示数据只铺在生成那一天。**我的 → 重置演示数据** |
| 改完代码模拟器还是旧的 | 这个 IDE 热编译不可靠。**关掉项目窗口再重开**，不要靠热重载 |
| 页面白屏 / 只剩导航栏 | 编译缓存坏了。清编译缓存后重开项目 |
| Console 出现红色 error | 停下，截图发我，别硬着头皮录 |
| Console 只有蓝色 `[system]` 或黄色 preload 提示 | 正常，判据是**没有红色** |
| 照顾分环是纯色圆、没有进度弧 | 基础库版本低，告诉我，我换成兼容写法 |
| 体重图空白 | 切一次别的 tab 再回来会重绘；仍空白就发我截图 |
| 弹窗遮住关键画面 | 等 toast / 弹窗消失再继续 |
| 录出来鼠标抖 | 别用触控板 |
