## 录制前 5 分钟准备（按顺序做，别跳）

1. 开发者工具打开项目，窗口最大化；模拟器机型选 **iPhone 12/13（375 宽）**，缩放 100%
2. 进 **我的 → 重置演示数据** → 恢复初始三只猫，保证起始画面干净
3. 关掉微信 / QQ / 钉钉通知，关掉桌面其它窗口（避免录进隐私）
4. 录制区域**只框开发者工具窗口**，不要录整个桌面
5. OBS 参数：窗口采集 → 微信开发者工具；1920×1080 / 30fps / MP4 / 码率 6–8 Mbps
6. 鼠标移动放慢，**每次点击前停 0.5 秒**，让观众看清点在哪
7. 旁白可以边录边说，也可以录完静音再配（推荐后者，口误可以重来）

> 环境音要干净：用耳机麦或手机贴近，别用笔记本内置麦在空调房录。

## 分镜表

### 镜头 1 ｜ 0:00 – 0:15 开场

**画面**：开发者工具全貌（左边模拟器、右边文件树）
**操作**：鼠标在左侧文件树上轻轻划过 `pages/`、`utils/`
**旁白**：

> 这是作业四的喵管家小程序，微信原生框架，WXML + WXSS + JS 三件套，没有用云开发也没有第三方库。项目里四个页面：首页、记录、我的、猫咪档案。

---

### 镜头 2 ｜ 0:15 – 0:50 首页与多猫切换

**画面**：首页
**操作**：依次点顶部三个猫头像（团子 → 芝麻 → 豆豆），每次停 1 秒；指一下三个状态环
**旁白**：

> 首页是猫咪状态总览。上面这排可以切猫，每只猫有独立的档案和数据。中间三个环分别是饱食度、饮水度和心情值，下面这行是体重和相比上次的增减。今日摄入按克数统计，进度条对应每只猫的每日目标，目标值是可以在档案里单独设的。

---

### 镜头 3 ｜ 0:50 – 1:35 四个快捷操作（核心演示）

**画面**：首页快捷操作区
**操作**：
1. 点 **投食** 两次 → 看饱食度环和今日摄入条同时变化 + 顶部 toast
2. 点 **喂水** → 看饮水环
3. 点 **逗猫** → 看心情环
4. 点 **称重** → 弹窗里输入 `4.68` → 确定 → 体重数字和趋势箭头更新
**旁白**：

> 四个快捷操作。投一次食是四十克，饱食度和今日摄入会同步往上走，同时自动生成一条记录。称重会弹一个输入框，输入当前体重，数字和趋势箭头立刻更新——这里的箭头是跟上一次称重比的。

---

### 镜头 4 ｜ 1:35 – 2:15 记录页与体重曲线

**画面**：切到「记录」tab
**操作**：
1. 停 1 秒看折线图（这是视觉重点）
2. 点上面切到另一只猫 → 曲线整体换一套数据
3. 点筛选「喂食」→ 列表只剩投食记录
4. 点回「全部」，往下滚时间线
**旁白**：

> 记录页。上面这张体重趋势图是用 canvas 2d 手画的，包括渐变填充、数据点、坐标轴刻度，按设备像素比做了适配，不是贴图。切换猫咪曲线会换成那只猫的数据。下面是全部记录，按天分组，可以按类型筛选，比如只看喂食。

---

### 镜头 5 ｜ 2:15 – 2:50 设置与档案编辑

**画面**：切到「我的」
**操作**：
1. 关掉「循环饮水机」开关 → 顶部"几台在线"数字变化 → 再打开
2. 点「每日提醒时间 → 修改」→ 选个时间 → 确定
3. 进「猫咪档案」→ 点最下面「＋ 添加」→ 填名字「奶糖」、选性别「妹妹」、体重填 `3.5`
4. 点「换头像」→ 选一张**你自己的猫照片** → 保存档案
**旁白**：

> 我的页面。设备开关是模拟的三个外设，关掉一台，上面的在线数量会跟着变。提醒时间可以改。档案这边可以新增猫咪，头像直接用自己拍的照片——选完会存成本地永久路径，重启小程序也不会掉。

---

### 镜头 6 ｜ 2:50 – 3:05 回到首页看结果

**画面**：切回首页
**操作**：停 1 秒 → 新猫出现在顶部切换条 → 点它，看它的独立数据
**旁白**：

> 保存后回到首页，新猫已经在切换条里了，数据是独立的。

---

### 镜头 7 ｜ 3:05 – 3:30 Console 无报错（作业硬性要求，别省）

**画面**：底部面板切到 **Console**
**操作**：
1. 点 Console 面板的 🚫 **清空**按钮
2. 回模拟器点两三个快捷操作
3. 鼠标停在 Console 空白区，停 2 秒
4. 顺手点一下 **Network** 面板，展示"没有任何网络请求"
**旁白**：

> 最后检查控制台。我先清空，然后再操作几次——可以看到控制台没有任何红色报错。因为整个小程序不联网，数据都在本机存储里，所以也不存在请求失败。这个是 Network 面板，确实一条请求都没有。

## 常见翻车点

| 现象 | 处理 |
| --- | --- |
| Console 出现红色 error | 停下，截图发我，别硬着头皮录 |
| Console 只有蓝色 `[system]` 信息 | 正常，不是报错，判据是**没有红色** |
| 状态环是纯色圆、没有进度弧 | 基础库版本低，告诉我，我换成兼容写法 |
| 体重图空白 | 切一次别的 tab 再回来会重绘；仍空白就发我截图 |
| 弹窗遮住关键画面 | 重新点一次，等 toast 消失再继续 |
| 录出来鼠标抖 | 别用触控板，用鼠标；移动时慢速直线 |
