# 图片来源

仓库里 `miaoguanjia/images/cats/` 下的三张猫头像是 **Pexels 免费授权照片**，
不是本项目作者养的猫。三只猫（团子 / 芝麻 / 豆豆）的档案是虚构的演示数据，
名字与照片的气质对得上，但它们并不是同一只真实存在的猫——录屏和报告里都不应
把它们说成"我养的猫"。

## 加工方式

原图下载后统一压到 **1200×800（3:2）**、JPEG q82、progressive、约 60–90 KB，
与首页照片槽比例一致，所以 `aspectFit` 下既不裁切也不留边。

复现命令：

```bash
python tools/prep_cat_photo.py 原图.jpg miaoguanjia/images/cats/cat1.jpg --width 1200
```

三张原图都是 3:2，等于只做了缩放，没有裁掉画面内容。

## 为什么不直接用 AI 生成

第一章把"不做生成式 AI"写成四条硬约束之一（个人主体做不了对应类目）。那条约束
针对的是**产品能力**，拿 AI 生成的图当"真猫照片"并不违反它；真正会出问题的是
README 里"换成你自己的猫照片"这句承诺——图既然是编的，演示视频里那只猫就成了
一句没法核实的陈述。用授权实物照片，来源可查、可复现，也不用向谁解释。
