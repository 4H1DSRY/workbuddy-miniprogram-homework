# 2026-10-28 喵管家（homework-4）

## 1. 心情行最右一格缺右边框（用户自测发现）
- 根因：`border: 1rpx` 在 750rpx 基准下是半个 pt，@3x 屏上 1.57 物理像素。
  五个方格宽度 88.8rpx 非整数，最后一格落在半像素位置，四边被抗锯齿分摊比例不同，
  右边摊成一片浅灰 → 视觉上「没闭合」。
- 修法：`border: 2rpx`（≈1pt / 3 物理像素），方格 18→20rpx，`box-sizing: border-box`。
  实测五格四边全部闭合（`_shots/z_m3.png`）。
- **教训：小元素（< 24rpx）不要用 1rpx 描边**。1rpx 只在长直线（分隔线、边框）上稳，
  短边的端点位置不可控。

## 2. 照片四角改圆角
- `.photo-slot` 与 `.photo` 都加 `border-radius: 12rpx`（≈6pt）。
- 先试 4rpx（≈2pt），截图放大后**看不出圆角**——视网膜屏上 2pt 的弧只有 2-3 个物理像素，
  被抗锯齿吃掉一半。12rpx 才明确可见。
- 两处都要写：槽位负责裁溢出，图片自己也要圆，否则 aspectFit 留白时图片的直角压在圆角槽位上。
- 注意 `.photo` 是 `width/height: 100%` 铺满槽位，只给槽位写圆角也不够（image 的直角会盖住）。

## 3. 照顾分弧色改成 0 分红 → 100 分绿
- 新增 `theme.scoreColor(percent)`：HSL 线性插值，h 8°→135°，s 0.64→0.48，l 0.44→0.36。
  色阶：0 `#B83C28` / 40 `#A4A22C` / 60 `#6E9A2E` / 69 `#58962E` / 100 `#308846`。
- 返回 **hex 而不是 `hsl()`**：simulate.js:165 断言 `conic-gradient(#` 开头，且 hex 在模拟器与真机一致。
- 零分端点刻意不等于品牌朱 `#AE412D`（用 `#B83C28`）：同一屏里品牌色与告警色不该是同一个值。
- **副作用**：首页「唯一朱色焦点是照顾分」这条设计规则作废，wxml 注释改为「唯一的彩色焦点」。
  品牌朱仍在底部面板按钮、`showModal` 的 confirmColor。
- simulate 128 → **132**：0 分红、100 分绿、两端色差>90、60 分已偏绿。
  （simulate.js 原本没 require theme，新断言前要补 `const theme = require(...)`。）
