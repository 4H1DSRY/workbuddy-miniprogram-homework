顺带澄清一个易混点：侧边栏底部的「空间 / 资料库」是**云端**文档存储（Library），和工作空间（本地文件夹）是两套东西。

## 2026-10-23 · G11 症状入口提到首页（用户选 C 方案）

- **背景**：用户在实际工具里找不到「初诊 / 记录症状」——原入口只在记录页最底部（`records.wxml` 末尾），记录一多要滑很久；文案「身体不适？记录症状」也不含「就诊」，搜不到。
- **方案**：用户在我给的三选一里选了 C（放进首页快捷操作），尽管我标了"会溢出"。所以实现上必须**不加高度**：首页一屏预算只剩 52rpx，新开一行必溢出 → 5 列均分（每列约 130rpx），容得下 2 字标签。实测未挤压「今天 · N 条记录」。
- **实现**：`index.wxml` 加第五个 `.act`（`bindtap="onSymptom"`，图标复用 `images/icons/doc.png`）；`index.js` 加 `onSymptom()` → `navigateTo` 症状页；文案收成「症状」（与前四项 2 字节奏一致）；记录页旧入口保留。
- **设计约束**：首页唯一朱色焦点仍是「今日照顾分」，第五个入口不做色块、不用朱色。
- **返回层级零改动**：`report.onDone` 本就按「栈里上一页是不是症状页」判断，首页进入 → `delta 2` → 回首页，已加断言锁住。
- **测试**：`e2e.js` 新增【O】段 7 条（67 → 74）。踩了一次坑：`e2e.js` 里已存在【N】标签（换猫历史不串），我用 python 按 `console.log('\n【N】')` 定位插入，结果定位到旧的【N】、顺手把【G】段的 `sym2` 改名成 `symHome` 导致重复声明。**结论：往共享脚本插段落前先 `grep -n '【'` 查重标签。**
