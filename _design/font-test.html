四 条 路 线

字体族字号 · 字重 · 字距代价
A 苹方 → 雅黑 / Noto Sans 名字 31/300 · 数字 40/300 就是现在这样。层级靠字重撑，31 与 40 只差 1.29 倍，等于没有主次
B 名字与数字用宋体，其余用黑体 名字 33/400 · 数字 44/400 · 字距 0.12em 宋体在 Android 上大概率回退成黑体，标题风格会变弱（但不会崩）
C 全部宋体 名字 33 · 数字 44 · 字距 0.14em 11px 的小字用宋体会发糊，横画细到下笔不清；Android 上整体退化风险最大
D 全黑体，靠字重与字距 名字 35/200 · 数字 46/200 · 字距 0.16em 跨平台最稳；但 200 字重在很多安卓机上没有，会被合成出来，边缘发灰
先说清楚一件事：这个页面是在 Windows 上渲染的，不等于真机。 你看到的宋体是 STSong / 思源宋体，iOS 上会换成 Songti SC（更秀气一些）， Android 上则很可能拿不到任何中文衬线字体、直接回退成黑体。 所以 B 和 C 的“宋体质感”只在 iPhone 上成立——这也是我给 B 标推荐、而不是 C 的原因： B 把宋体限制在标题与数字上，即使回退，损失的也只是风格而非可读性。
