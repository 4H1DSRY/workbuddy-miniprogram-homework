# 症状清单的医学依据

日期：2026-10-22
用途：为「症状记录」页提供分类与选项的推导依据，不是诊断标准
方法：**兽医临床记录体系（SOAP-Subjective + 系统回顾）→ 常见猫病谱 → 反查清单覆盖**

---

## 零、先说结论

上一版的分类是凭常识分的，漏了三类东西：

1. **疾病的"反向"表现**：只列了食欲下降，没列食欲变好。但甲亢和糖尿病的典型表现恰恰是"吃得很多却掉体重"。
2. **神经与骨科**：没有"后腿无力"，而这一个是 HCM 动脉血栓（数小时内致死）和糖尿病神经病变的共同信号。
3. **被毛与理毛**：CKD、甲亢、口腔疼痛都会让猫停止理毛。这是猫科特有的、很容易被忽略的早期信号。

## 一、体系：兽医怎么采集病史

### SOAP 里的 S（Subjective）

兽医记录分四段（Subjective / Objective / Assessment / Plan），只有 S 段是"主人能提供的"，也正是本产品要采集的部分。S 段的标准字段：

| 字段 | 对应本产品的组 |
|---|---|
| Activity level | 精神与活动 |
| Appetite / water intake | 吃喝 |
| Urination / defecation | 排尿、吐与排便 |
| Weight / coat condition | 体重与被毛 |
| Duration、previous treatment | 持续多久、自由描述 |

### 系统回顾（review of systems）

兽医问诊按身体系统逐项过一遍，标准顺序是：一般状态 → 消化 → 泌尿 → 呼吸 → 眼 → 耳 → 口腔 → 皮肤 → 神经 → 骨科。本产品的分组顺序照此，只把"眼"和"耳"合并（主人能区分，但同屏放得下）。

**这不是我编的分类，是兽医问诊表的固定结构。**

## 二、常见猫病谱 → 症状映射

下面每一行都能回答"为什么清单里必须有这一项"。流行率数据来自公开文献与机构科普，标注见第四节。

| 疾病 | 流行率 | 典型早期表现 | 对应清单项 |
|---|---|---|---|
| **慢性肾病 CKD** | 一般猫 1.2%；>9 岁 3.6%；15 岁 >80% 有证据 | 多饮多尿、渐进掉体重、食欲下降、间歇呕吐、**被毛粗乱**、口臭带化学味 | 喝水变多、尿量变多、体重下降、食欲下降、呕吐、理毛变少 |
| **甲亢** | >9 岁达 11.4% | **食欲好却掉体重**、多饮多尿、**烦躁多动**、**叫声变多**、间歇呕吐/腹泻、被毛乱 | 食欲变好/总讨食、体重下降、喝水变多、烦躁易怒、叫声变多、呕吐、腹泻 |
| **FLUTD / 尿闭** | 约 4% | 蹲猫砂盆努责、频繁少量尿、**盆外排尿**、血尿、**过度舔生殖器** | 频繁进猫砂盆、蹲很久尿不出、尿里带血、猫砂盆外乱尿 |
| **糖尿病** | 0.5–1%；肥胖猫高 2–4 倍 | 多饮多尿、**多食但掉体重**、嗜睡、**后肢无力**、果味口气 | 喝水变多、尿量变多、食欲变好、体重下降、**后腿无力/拖行** |
| **牙病 / FORL** | 3 岁 70%，老年 >80%；FORL 6 岁 60% | 口臭、**掉食**、单侧咀嚼、**只吃软食**、流涎、牙龈出血 | 口臭、吃饭偏头/掉食、只吃软食、流口水、牙龈出血 |
| **IBD** | 常见 | 慢性呕吐、腹泻、体重下降、食欲下降 | 呕吐、腹泻/软便、体重下降、食欲下降 |
| **上呼吸道感染**（FHV/FCV） | 多猫家庭与幼猫高发 | 打喷嚏、鼻分泌物、**结膜炎/眼分泌物**、食欲下降、发热 | 打喷嚏/流鼻涕、眼部分泌物、眼睛红/睁不开、食欲下降 |
| **皮肤真菌（猫癣）** | 幼猫、老年、长毛猫高发 | 圆形脱毛斑、皮屑、断毛、红斑 | 局部掉毛、皮肤发红/结痂 |
| **骨关节炎** | >15 岁约 35.9% 有报告 | **不愿跳上跳下**、跛行、僵硬、局部过度舔舐 | 跛行/不愿跳、走路不稳 |
| **肥胖** | 城市猫约 60% | 体况评分高 | 体重数据（自动带，不勾选） |
| **肝脂质沉积** | 肥胖猫禁食 2–3 天即触发 | 完全不吃、呕吐、精神沉郁、黄疸 | **完全不吃**、呕吐、没精神/不爱动 |
| **HCM** | 缅因/布偶有遗传型 | 呼吸困难、**后肢突然瘫痪**、虚弱 | 张嘴呼吸、**后腿无力/拖行** |
| **癫痫 / 神经** | — | 抽搐、转圈、共济失调 | 抽搐、走路不稳/转圈 |
| **中毒 / 误食** | 户外猫高发 | 流涎、呕吐、抽搐、精神沉郁 | 误食/接触毒物、流口水、呕吐 |

### 反查：清单里有没有"孤儿项"

每一项都必须能对应到至少一种疾病，否则是噪音。抽查几个容易变成孤儿的：

| 清单项 | 覆盖的疾病 |
|---|---|
| 叫声变多 | 甲亢、疼痛（口腔/骨关节）、认知障碍（老年猫） |
| 理毛变少 / 被毛乱 | CKD、甲亢、口腔疼痛、肥胖（够不到） |
| 猫砂盆外乱尿 | FLUTD、关节痛（进不去盆）、应激 |
| 只吃软食 | FORL、牙龈口炎、下颌骨折 |
| 黑便 | 上消化道出血（溃疡、肿瘤、误食） |

## 三、分诊：红旗项与响应速度

分诊（triage）不是按"症状多少"排，是按时限排。三档：

| 档 | 含义 | 触发项 | 界面文案 |
|---|---|---|---|
| **急诊** | 数小时内可致死，立即就医 | 蹲很久尿不出、张嘴呼吸、抽搐、后腿突然拖行、误食毒物/百合等 | 「请立即就医」 |
| **急** | 24 小时内就诊 | 便中带血/黑便、持续呕吐、完全不吃超过 24 小时、眼睛突然睁不开 | 「建议今天或明天就诊」 |
| **常规** | 可预约，继续观察记录 | 其余 | 「可先观察，继续记录」 |

**为什么"蹲很久尿不出"是第一优先**：公猫尿道阻塞 24–48 小时可致死，是所有项里时间窗最短的。

**为什么"完全不吃"是急诊级**：肥胖猫禁食 2–3 天即可触发肝脂质沉积，这是猫特有的、比狗危险得多的机制。

## 四、数据来源与可信度

| 数据 | 来源 | 类型 |
|---|---|---|
| CKD 1.2% / 3.6% / 80%·15 岁 | petadoptnow 汇总 | 二手科普 |
| 甲亢 >9 岁 11.4%、FLUTD 4%、糖尿病 0.5–1%、牙病 70%/80%、FORL 60%、肥胖 60% | RSPCA / petadoptnow / spectrumcare | 二手科普，多家口径一致 |
| 关节炎 35.9%、甲亢 13.9%、牙病 31.3%（2010–2015 调查） | PMC7557453《Prevalence of Disease and Age-Related Behavioural Changes in Cats》 | **一手文献** |
| SOAP 与系统回顾结构 | 兽医病历规范（AVMA 记录标准相关材料） | 体系性来源 |

**必须声明的局限**：

- 这些是**人群流行率**，不能用于个体判断。清单里出现某项，不代表猫得了对应疾病。
- 我不是兽医，本文档只服务"该采集哪些观察项"，**不产出鉴别诊断**。
- 红旗项清单是产品规则，不等于临床分诊标准；实际紧急程度必须由执业兽医判断。
- 中国城市猫的疾病谱与欧美数据可能有差异（如散养比例、疫苗覆盖率），后续宜用本地数据校准。

## 五、由此得出的最终分组

10 组、39 项。相比上一版新增的关键项（都对应明确疾病）：

| 新增项 | 补的是什么缺口 |
|---|---|
| 食欲变好 / 总讨食 | 甲亢、糖尿病——只列"食欲下降"会整类漏掉 |
| 叫声变多 | 甲亢、疼痛 |
| 后腿无力 / 拖行 | HCM 血栓、糖尿病神经病变 |
| 抽搐 | 癫痫、中毒、低血糖 |
| 跛行 / 不愿跳 | 骨关节炎（老年猫 35.9%） |
| 理毛变少 / 毛乱 | CKD、甲亢、口腔痛 |
| 只吃软食 | FORL、口炎 |
| 牙龈出血 | 牙周病 |
| 黑便 | 上消化道出血 |
| 误食 / 接触毒物 | 中毒，且是急诊项 |
| 猫砂盆外乱尿 | FLUTD、关节痛 |

同时删掉/合并：

- 「喝水变少」保留（与变多成对，指向不同方向），但不再单列"饮水异常"
- 「频繁吐毛球 / 干呕」合并为一项（毛球本身正常，频繁才是信号）
- 「体重下降」保留为主观项，但报告里以数据层的客观体重为准
